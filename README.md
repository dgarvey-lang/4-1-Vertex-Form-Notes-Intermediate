# 4-1 Notes Vertex Form

An interactive, step-by-step discovery lesson for y = a(x − h)² + k.

Open `4-1 Notes Vertex Form.html` in a browser (or turn on GitHub Pages for this repository) to use it.

Steps:
1. Meet the parent function y = x²
2. Explore what **a** does (reflection, wider, narrower)
3. Explore what **h** does (left / right)
4. Explore what **k** does (up / down)
5. Predict, then check: −(x − 4)² and (x + 3)² − 5
6. Summary of the rules
7. Practice: find the vertex and whether the graph opens up or down
